Projeto de SPDA para condomínios

Defina uma solução adequada para proteger o prédio

O SPDA é o sistema de proteção contra descargas atmosféricas, conhecido no dia a dia como sistema de para-raios.
O projeto organiza como o SPDA será formado e instalado. A WX2 avalia as características do condomínio e define uma solução para a parte superior, as descidas e o aterramento.

O que podemos entregar

  • Análise de risco, quando necessária;
  • Projeto da parte superior, descidas e aterramento;
  • Avaliação do uso das armaduras naturais;
  • Detalhes e especificações para a execução;
  • Orientações para instalação e compatibilização;
  • ART e documentação técnica;

Qual solução combina com o seu prédio?

A solução depende das características do prédio. Quando a estrutura de concreto puder ser aproveitada, isso pode simplificar a instalação; caso contrário, o projeto indica uma solução própria para descidas e aterramento.
